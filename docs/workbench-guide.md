# 直播工作台（v0.4.0）

主导航的「直播助手」集中放置开播准备、互动处理和下播复盘。原来的弹幕、数据、房间和设置仍可单独使用。

## 开播前

1. 登录后可选择「我的直播间」、最近使用或收藏的房间。房间管理会显示当前账号与主播身份；开播、关播、标题和分区操作在后端检查房主权限，关播还需确认。
2. 打开「演练」，输入模拟观众和消息，查看当前播报配置与自动回复规则的结果。登录页也可直接进入演练。演练不会公开发送弹幕、消耗规则冷却或写入正式直播记录；「试听」会在本机发声。
3. 打开「声音」，选择输出设备，试听并检查音量。每行 `原词=读法` 保存发音词典；观众卡片还可设置某个 UID 的专属读法。设备断开会报错，不会偷偷改用另一个设备。声音是否进入直播由 OBS 的采集路径决定。
4. 在「场景」预览并应用游戏、聊天、休息预设，或保存当前整套设置。场景包括主窗口字号/密度、悬浮窗、OBS 外观、播报、自动回复及定时公告。可撤销最近一次切换；账号、推流凭据和 OBS/VTS 连接密码不进入场景。

## 直播中

- **待处理消息**：SC 自动进入；最近互动可手动加入、标记已读，或明确置顶到 OBS。待处理区最多 200 条，超限有提示，较早的 SC 仍可在完整场次记录中查找。
- **观众卡片**：点击主弹幕中的名字，按 UID 查看本地记录、首次/最近出现时间、称呼、备注和专属发音。同名观众分开统计。备注不发送给平台、不进入 OBS 或伴随屏。
- **参与队列**：设置报名、退出口令并开启接收；支持 `报名`、`报名 内容`、`报名：内容`。同一个 UID 不能重复排队。可人工添加、叫号、移到队首、完成、取消；OBS 可显示前 8 位。队列最多 200 位待处理观众，历史最多 400 项。
- **快捷键**：默认 ⌘⇧D 显示主窗口、⌘⇧L 切换悬浮窗锁定、⌘⇧M 静音、⌘⇧K 添加时间标记。在「设置 → 通用与数据」修改；快捷键冲突会提示。标记需要已有记录场次。
- **公开画面**：OBS 的消息开关独立于主播端过滤。管理警告默认仅主播可见；只有主动置顶的消息和开启展示的参与队列会追加到公开页面。OBS 设置显示实际服务地址，保存样式后已连接的页面自动刷新。

## 手机 / iPad 伴随屏

在同一可信局域网中打开「伴随屏」，开启服务后扫码配对。配对码 5 分钟内有效且只能使用一次；添加另一台设备需生成新码。最多 8 台设备，支持逐台撤销或关闭全部。应用重启需要重新配对。

伴随屏能查看近期消息与待处理消息、标记已读、静音播报；没有发弹幕、关播、修改账号或配置的权限。它默认关闭，使用本地 HTTP，不提供公网访问或端到端加密。Wi-Fi 切换后如果 Mac 的地址改变，需要重新打开地址；休眠期间不保证浏览器继续轮询，回到前台会重试。

## 下播后

「复盘」按场次浏览数据库中的完整记录，支持 UID、房间与消息类型筛选、分页、付费支持排行。汇总覆盖完整场次，免费礼物不计入付费总额；金额表示平台事件金额，并非税后结算收入。

时间标记保存当时之前约 30 秒的近期互动上下文。默认零点是本地首次连接时间，可校准为录像起始时间；导出包含原始时间戳、相对秒数、时间码和标记上下文。应用并没有读取或校时录像文件。瞬时网络重连延续当前场次；主动断开、换房或新一轮直播另起场次。

完整 JSON 导出固定在导出开始时已入库的记录范围，分页写入临时文件后替换目标文件，避免高峰期新增消息造成分页重复。导出失败会清理临时文件并保留原文件。

可以删除已结束场次、设置历史保留天数（0 表示永久保留），并手动回收数据库空闲空间。清理不删除当前场次；观众历史随记录清理同步减少，单独保存的私人备注继续保留。

## 配置与更新

配置导入先展示将更改的配置类别，可合并或覆盖。确认时校验文件是否发生变化，先备份再应用；失败尝试回滚，并可恢复最近一次备份。配置导出可能包含连接密码，应由自己妥善保管。

更新检查随应用启动运行，下载优先匹配当前 CPU 架构；通用包可作为兼容候选，不会把另一种架构的包误当成更新。

## 验证范围

已覆盖本机 Rust 单元/HTTP 集成测试、前端交互测试、模拟数据浏览器检查和独立原生实例。SEND_GIFT_V2 按上游已合入的 protobuf 字段实现，覆盖批量礼物、金额和新旧事务去重；尚缺本项目账号收到的独立真实 V2 样本。实体手机锁屏、实际直播中的声音采集、真实房间开关播及高峰负载仍需实际场景验证，不把模拟演练等同于平台送达。

新增在线 TTS、可视化 OBS、点歌与音乐、多来源评论、翻译和投票，详见[主播工具扩展](creator-toolkit.md)。音乐支持本地播放及外部播放器联动；多平台能力用于评论聚合，不包含多平台推流。
