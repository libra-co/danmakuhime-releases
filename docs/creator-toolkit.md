# 主播工具：声音、OBS、点歌、联播、翻译与投票

2026-09-06 更新。入口沿用「直播助手」和「设置 → OBS」，无需额外运行脚本。

## 声音

「声音控制 → 选择你的声音」可以浏览并搜索 macOS 系统音色，或选择 Azure Speech、自定义 HTTP 服务。先测试当前配置，再保存并试听。在线合成返回的音频由应用播放到所选输出设备；失败时可自动使用本地语音，界面显示失败原因。停止、跳过、静音或更换供应商会取消正在进行的合成和播放。

Azure 填资源密钥、服务地址与音色 ID（例如 `zh-CN-XiaoxiaoNeural`）。区域地址示例 `https://eastasia.tts.speech.microsoft.com`；也支持 Azure 资源的 `*.cognitiveservices.azure.com` 地址。读取音色列表使用当前草稿，无须先保存。

自定义服务接收 POST JSON `{ "text": "你好", "voice": "voice-id", "rate": 200, "format": "wav" }`，直接返回 WAV、MP3、FLAC 或 OGG 字节。填写密钥时附带 `Authorization: Bearer ...`。远程服务使用 HTTPS，本机服务允许 HTTP。在线语音与音乐使用独立播放器；进入 OBS 的音频仍由主播选择的采集路径决定。

场景保存不携带在线语音供应商或密钥；应用场景保留当前已配置的服务连接。完整配置备份仍包含连接配置。

## OBS 外观

在「设置 → OBS」打开可视化编辑器，调整字体、字号、间距、圆角、颜色、背景透明度与描边，选择列表或横向滚动。滑动控件即时更新嵌入预览，点击「应用到 OBS」后公开画面生效；预览不连接真实弹幕流。

B 站与 Twitch 原生表情随消息显示；也可上传 PNG、JPEG、GIF、WebP，将指定文字替换成自定义表情。每张图片小于 700 KB，最多 100 个，总配置大小有上限。图片加载失败时回退文字。这里提供自定义表情表，不会自动下载第三方平台的完整表情库。

主题可导出为 JSON，导入后先进入草稿预览。主题仅包含外观及表情资源，不包含密钥或私人备注。列表最多保留 50 条；滚动模式按像素速度分配轨道，待显示队列最多 60 条。

## 点歌与音乐

先选择本场直播的模式。两种模式分别排队，切换后保留请求，正在播放或演唱时先停止或完成当前曲目。

- **点歌给主播唱**：建立可唱曲目，观众发送 `点歌 歌名`，主播确认曲目后加入待唱列表。开始后记录演唱状态；点击「演唱完成」结束。这种模式不自带伴奏，也不会自动播放音乐。
- **点歌播放音乐**：选择 B 站或本地音频曲库，再接收请求。流程为「选择音源 → 搜索歌曲与版本 → 检查可播放 → 审核入队 → 实际播放 → 播完下一首」。

B 站支持歌名、歌手关键词搜索，以及 BV 号或视频链接。关键词结果显示视频标题、上传者和时长；合集必须点击「选择分 P」确认具体曲目，避免误播第一首。应用从 B 站取得临时音频地址、下载并解码检查，成功后才开放「审核入队」。审核不会立即发声。登录状态复用应用内 B 站账号；删除、仅试听、无独立音轨、请求受限或音频无法解码时显示原因，允许重试或切换本地音频。

点击「开始下一首」后由应用内播放器输出声音。显示加载、播放、暂停和失败状态；失败可重试，停止可取消正在加载的音频。「歌曲播完后自动播放下一首已审核曲目」需要显式开启，只在音乐模式生效。应用内音量与输出设备独立于 TTS，进入 OBS 的声音仍由主播选择的音频采集路径决定。

本地音频支持 WAV、MP3、FLAC、OGG，可选择文件或粘贴完整路径，文件需保留在原位置。保存到曲库后仍需检查再审核。旧版网易云、Apple Music、Spotify、YouTube 等网页条目保留记录，但不能直接加入播放队列；需重新选择 B 站版本或本地音频。本版本没有这些平台的在线搜索和播放服务。

点歌规则支持口令、接收来源、冷却、每人上限和重复控制。重名或未匹配请求由主播选择具体版本。OBS 可显示当前曲目、点歌人、最多 8 首待播歌曲；LRC 时间轴可显示当前歌词。

曲库最多 2,000 首，单次音频下载或本地文件最多 64 MB，每种模式活跃请求最多 200 条，两种模式合计保留最多 400 条请求和处理记录。检查结果有效期 5 分钟；修改音源需重新检查。后台最多两个搜索/检查网络任务，音频预备缓存只保存一首。

点歌设置和队列按主房间保存，曲库全局共享。旧版数据按房间迁移，不删除原记录。换房停止播放；重启后未完成歌曲回到待播，不自动发声。删除、屏蔽或改变曲目用途后，相关请求保留原始点歌内容并回到审核，避免失效歌曲卡住队列。

## 多来源消息

「多来源消息」可以增加最多 8 个额外来源，并与 B 站主房间一起使用。每个来源显示连接/重连状态，支持断开、配置、独立颜色、OBS 显示、原文/译文播报和自动翻译。声音的音量、类型开关、发音词典与过滤仍由「声音控制」统一管理。

- **B 站**：填写房间号或直播间链接，复用当前登录。长号和短号会解析为真实房间，防止重复连接。
- **Twitch**：填写频道、授权账号登录名和带 `chat:read` 权限的用户访问令牌。通过 TLS IRC 读取消息和表情，自动响应心跳。
- **YouTube**：填写直播视频链接或 11 位视频 ID，配置已启用 YouTube Data API 的密钥；需要授权的聊天室可提供 OAuth 访问令牌。轮询遵循平台返回的间隔，授权到期后需更新令牌。

额外来源需手动连接；断线会退避重试。统一消息区最多保留 500 条，支持来源/关键词/待处理筛选、单条朗读、翻译和 OBS 置顶，付费醒目留言自动标为待处理。它们可参与点歌和投票；原有场次统计、完整历史和伴随屏仍围绕 B 站主房间。

修改来源名称、颜色、OBS 显示等偏好不再重连；改变房间、平台或授权信息才重连。修改已连接来源时先检查新配置；检查失败保留原配置与原连接。把额外 B 站来源的真实房间设为主房间时，会断开重复来源。移除来源会取消其翻译任务、清除相关置顶，并从 OBS 移除该来源的现有消息。

「复制独立 OBS 地址」会带上来源筛选参数，例如 `?source=<来源 ID>`；`?source=main` 仅展示主房间，多来源可用逗号分隔。它只决定这张浏览器源显示哪些评论，不改变已合成的直播视频。

## 弹幕翻译

配置 DeepL Free / Pro 或兼容服务后，选择目标语言、自动翻译语种、OBS 原文/译文展示方式和主房间播报方式。额外来源在各自配置中开启自动翻译。单条消息可以手动翻译、失败重试、朗读原文或译文。

自动翻译先在本机筛查明显的中日韩文字，其余交由 DeepL 自动识别；只展示符合所选语种的结果，手动翻译不受语种筛选限制。识别不确定的语言可能仍需提交服务并计入用量。选择译文播报时，不需翻译、服务失败、队列满或达到上限会读原文；手动重试不会额外触发自动朗读。

每日上限按本机日期和提交字符数保存，重启不重置当天用量，测试与正式翻译共用额度。并发最多 3 条，排队最多 100 条，单条最多 2,000 字；成功结果缓存最多 300 条。失败请求也计为已提交，服务实际账单以供应商为准。修改服务连接、目标语言、语种或启停状态后旧请求结果不覆盖新配置。只修改展示方式和额度保留现有译文；关闭主房间自动翻译会取消尚未完成的自动任务。中外文混合评论交由服务识别，不会因为含有中文人名就直接跳过。

断开来源、主房间换房、消息移出列表或更换翻译配置会取消相关排队与进行中的请求，已提交字符仍计入用量。取消不会补读原文；需要时可手动重试。每次请求使用独立标识，已经取消的旧响应不能覆盖重试结果或触发自动朗读。

## 弹幕投票

配置题目、选项、口令、时长与来源后开始投票。观众发送 `投票 1` 或 `投票 选项文字`；同平台的同一 UID 即使从不同房间投票也只计一票。支持自由回答、答案合并、提前结束和预设保存。

结果即时汇总，倒计时到期自动结束；OBS 展示可独立开关，结束后保留结果。每轮最多 20 个选项、20,000 位参与者；时长 10 秒至 2 小时。答案合并保留已有票数，仅可在投票结束后操作；投票进行中不能改题或切换预设，避免选项编号变化。最近 30 轮结果单独保留，新题目不会覆盖上一轮。

只计入时间戳位于本轮起止时间内、且在结束前收到的投票。开始前的历史补发与迟到弹幕不会混入新一轮。

## 独立插件与兼容

点歌、投票、多来源消息、翻译分别由 `MusicPlugin`、`PollPlugin`、`SourcePlugin`、`TranslationPlugin` 管理。四者拥有各自的命令通道、运行循环和业务状态，通过事件总线协作；慢速搜索或翻译不会阻塞其他模块。旧 `CreatorTools` 命令及 OBS 公开数据由兼容层转发和组合。

这些是应用内置 Rust 插件，随应用编译和升级。当前不提供第三方插件市场或动态加载外部二进制插件。

## 验证

本轮验收覆盖独立命令路由、翻译挂起时点歌/投票响应、来源与翻译并发保存、旧房间数据迁移、OBS 状态组合与私密字段排除；也覆盖音频检查先于审核、修改音源后重新检查、过期任务取消、曲目失效回到审核、进行中投票禁止改序号、历史结果保留及 OBS 编辑草稿不被轮询重置。

macOS 原生独立测试数据目录已完成：BV 点歌、合集选择分 P、实际下载和解码、检查前禁止审核、审核后入队、重启恢复、在线音频实际播放/暂停/恢复/停止、OBS 曲目与暂停状态同步，以及投票开始/结束/历史结果展示。低音量验收使用 B 站 335 秒的音频；额外的真实音频设备测试使用两首短 WAV，在零音量下验证暂停、恢复、完成并自动下一首。

B 站真实搜索与音频测试、真实音频设备测试均为显式运行的 ignored 测试，普通 CI 不依赖互联网或声卡。运行命令与本轮复审问题见 [复审记录](creator-review-2026-09-06.md)。

Azure、DeepL、Twitch、YouTube 仍未使用真实外部账号完成端到端验收；兼容 HTTP 服务及受控事件用于验证协议与生命周期。原生拖拽与文件选择器没有在本轮重新验收，相关输入和状态行为由前端回归及路径入口覆盖。
